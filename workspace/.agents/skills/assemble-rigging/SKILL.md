进入本阶段前，核对当前 body 版本与[身体绑定验收](../agentic-character/rigging/human-rigging/body-rigging/SKILL.md#身体绑定验收)记录。缺少复核或有未解决的身体变形问题时，回到独立 body 修正并复测。通过后从用户选定的装配检查点另存工作副本。将验收后的身体和骨架按原装配坐标接回，沿用身体权重、接头和已有局部修正。用该身体给贴身衣片初始化权重，再按服装结构绑定袖口、宽裤腿和自由裙片，交付完整身体可见的 Blender 工程。项目内的装配脚本位于仓库的 `avatar-motion/`。

## 完整角色的默认流程

从最终静态装配中单独取出 body，先按 body-rigging 定位双膝和双肘，核对全身骨点，再用单关节屈伸和目标动作验收身体。多角色任务逐个放行。身体通过后，将头颈接入同一骨架。逐角色核对当前版本的[下颌保形与颈缝闭合硬约束](../agentic-character/rigging/human-rigging/body-rigging/SKILL.md#下颌保形与颈缝闭合硬约束)，两项通过后再绑定头发、衣物和鞋，按该角色的发型、裙型和目标动作重算二级动态。待复核角色交付独立身体动作，标出缺少表面支撑的关节或异常变形位置；修正后从身体验收继续。

整装默认交付可编辑的静态绑定与动作工程，以及关键姿态复核图。根据当前动作挑选少量轮廓变化明显的时刻，例如双腿交叉、抬膝峰值和落腿回摆；从全段几何检查中补入实际穿插或拉伸最严重的帧或子帧。只渲染选中的时刻，注明帧号和选帧理由。需要定位变形来源时，同帧同机位并排查看独立身体与着装角色。单帧难以判断抖动或回摆时补看相邻子帧；用户要求视频时再按指定范围出片。逐角色记录双腿自交、裙摆与腿及鞋的帧间接触、可见的拉伸或上翻，以及完整调试耗时。角色参数、视频和实测结果保存在 case 中。

### 肩袖连接区的硬约束

对于覆盖肩头或腋下的衣服，在静置衣面标出左右袖窿、邻接衣身和袖根，保留设计开口。分区用于约束自由袖骨的作用范围；同一块布跨分区的网格边、以及实际缝合的对应点，都要进入验收。按衣面连通距离建立过渡带，使肩头继承躯干、锁骨和同侧上臂的连续支撑，向自由袖段逐渐引入袖骨。检查自由袖骨是否随上臂重复施加旋转，或在接缝单侧突然取得主导权重。

重开动作工程，在同一时刻依次读取静置、单独蒙皮和最终衣面。分别检查双侧肩袖与完整身体的相交、原接缝两侧间距变化，以及过渡带内和跨分区边的伸长、三角形退化。保留最差边索引、静置长度、绝对增量和两端有效骨权重，极短边单列。抬臂、前伸、收臂及相邻子帧用同机位局部复核；临时隐藏遮挡头发观察肩头。袖口周长、裙摆检测或旧动作烘焙均不能替代此项。任一侧缺测、有新增可见露肤、裂口或尖角，整衣验收失败。修复后同时复测相邻衣身，避免将拉伸转移到下一圈边。

### 跨动作极端姿态复核

用不同动作覆盖不同的受力姿态。按角色身高归一化双踝水平间距和最低鞋底离地高度，结合膝屈角、左右脚高度差及骨盆转速，挑出同一时刻双脚离地且大幅分开的跳跃、着地缓冲、左右单腿侧踢或急转交叉步。先从现有动作选；缺少某种组合时可另建明确标注的压力测试动作。以实际骨点和鞋底轨迹确认动作特征，合并近似姿态，保留不同侧、不同受力方向及几何指标最差的样本。

前后跳的四帧复核保留前跳腾空、一次常规落地和后跳腾空，把另一次落地编成一脚在前、一脚在后且步幅较大的双脚站姿。按角色腿长控制可达范围，在同一连续动作里完成腾空到前后分腿着地，保留袖摆和转头。用角色朝向测双踝的前后间距，并分别测两侧鞋底相对站立基准的高度。按实际动作事件选帧，角色专用帧号留在 case 中。用同一动作和采样标准比较物理参数候选，连同布长、穿模和外观一起判断；参数冻结后，在未参与选择的普通动作上独立复测。

复用静置绑定和初始物性，各动作从起始状态顺序推进，保留起跳前蓄力和落地后的回摆。批量筛查只渲染选中的帧；接触与布长按原采样要求检查。区分初始绑定压力筛查和带最终接触、布长修正的成品验收。用筛查发现的共性问题调整初始化，再用未参与调参的动作验证泛化。分别记录覆盖的动作、实际渲染数及完整墙钟时间。

## 接回身体时核对来源

从该角色最近一次通过身体复核的记录取出身体源工程路径，并记录作为装配起点的工程。读取成品中 body 的实际 Armature 修改器，在新进程与身体源工程比较 58 根骨的静置矩阵、骨尾、父级、网格拓扑、顶点位置和身体权重。旧装配与其自身上一版相同，不能证明已接回选定身体。发现不一致时先查清版本并接回已验收身体，再继续二级绑定。

    blender -b --python-exit-code 1 -P .agents/skills/assemble-rigging/scripts/check_body_source.py -- reviewed-body.blend assembled.blend

静置数据相符后，在目标动作中单独显示 body，核对交叉步和抬腿时髋、膝、踝轨迹及双腿自身相交。有同动作源工程时比对同帧变形顶点，包括动作修正层；重新定向的动作需重新复核。将身体自交与裙装对身体、靴子的接触分别记录。

## 按发束排骨

先隔离头发，查看正、背、侧面，区分后发、贴脸束、扎束处、游离末端与独立发饰。在静态工程的世界坐标中沿实际发束记录从根到梢的折线。宽后发按可辨认的分区设置控制链，短发只给自由下缘排短链。跨扎束点的下段继承对应上段的末骨。将发饰与应当固定的发根留给头骨，并通过单束转动核对。

每个角色的 JSON 列表记录 `name`、世界坐标 `points`、当前网格尺度下的搜索半径 `width` 和可选的父骨名 `parent`。按当前发型重新确认导线和影响半径。

在项目根目录指定含 NumPy、SciPy 的 Python 为 `RIG_SCIPY_PYTHON`，执行以下命令。输入应为静态装配，输出指定另一个文件路径。工具对当前 HumanArmature 和 hair / hair-ornaments 对象拟合发链、重分配头发权重并读回复核末骨响应。

```sh
blender -b source.blend --python-exit-code 1 -P .agents/skills/assemble-rigging/scripts/apply_hair.py -- guides.json output.blend
```

把读回的骨位投影到同机位的原材质头发图，检查侧面深度和末骨是否到达本束发梢。静态排布与动作中的摆动、相邻束串动、穿肩分别验收。

### 发束覆盖与交付验收

1. 先在最终装配的原材质四视图标出所有可独立摆动的发束或宽发片分区，再映射到对象和顶点。检查合并在头部、分散到多个对象和共享材质的头发。逐区记录固定或可动、依据、根部及自由端的顶点样本；贴头短发可整区固定，随头发一起建模的耳朵和饰件单独判断附着点。
2. 为每个可动区指定其导线和骨链。已有发链时按清单补齐缺区。单对象拟合脚本会重建骨架上的 `Hair.` 骨；多对象共用骨架时应一次汇总建链，再分别写入各对象权重，逐对象调用该脚本会清除先前的链。
3. 重开交付绑定，按清单逐区读取实际变形骨架、父链和正权重。自由端样本应有本束末段权重。单独小角度转动末骨，在头部局部坐标量本束梢部、固定区、相邻独立束的位移，并恢复静置姿态。按发束尺度设定位移容差并记录结果。任何漏区、自由端无响应、根部滑动或明显串动均退回该束。仅统计零权重顶点、骨数或全对象最大位移，无法判定覆盖。
4. 将装配、绑定、覆盖报告及动作产物的来源 ID 关联起来。复用旧绑定前执行同一检查；缺少证据时重开补验。换绑定后从通过的版本重新生成所需动作，回读交付格式中的骨链和蒙皮，用转头或急停观察发梢相对头部的延迟与回摆。分别记录绑定覆盖和动态表现。

## 尾巴、翅膀和其他可动附属部件

整角绑定前，从装配四视图和网格逐项登记可独立运动的外伸部件。记录每条尾巴、每侧翅膀或其他附属部件所在的对象及顶点区、实际附着点、自由端和预期运动。对象名仅供定位。合并在衣物或身体里的网格也要分区检查。硬质部件需要相对身体转动时，设置独立的枢轴骨。

- 尾巴从真实附着处沿尾身中线排到尾尖，根部继承附着部位的骨。弯曲尾巴沿表面追踪走向，多尾分别建链和分配权重。用单尾侧摆检查根部稳定、尾尖响应和邻尾串动。
- 翅膀按左右及翼型分别建骨。翼根定位在躯干或配件的真实连接处，可折叠翼沿主要折点到翼尖建链，翼膜或羽片按支撑结构分权。分别做单侧展开、折叠，检查翼尖响应、翼根滑移、对侧串动与夹层拉伸。记录主动展翼控制和被动随动各自负责的骨段。
- 将应有部件清单逐项对照重开后的骨链、权重和局部动作响应；只跟随躯干的自由端、缺失的一侧或空的二级骨报告均不能通过。确实固定的装饰记录依据和刚性父骨。烘焙后再回读实际交付动作，核对绑定版本、左右控制和自由端运动。

### Pi 自动检查与补绑

Pi 在部件蒙皮后调用 [pi_secondary_gate.py](scripts/pi_secondary_gate.py)。[secondary_coverage.py](scripts/secondary_coverage.py) 用身体骨点和角色朝向建立局部坐标，沿真实网格连通域、材质分区、突出轮廓及相对附着位置提出发束、尾巴和左右翼的顶点区。一个对象可以包含多个候选区域。对宽发片再沿周向分区，对延伸的尾翼沿网格边距离布置骨节。根部到末端渐变分权，限定写入当前区域。

先审计现有权重，再对每个自由端单独转动控制骨，读取该区梢部、根部、其他自由端及同对象受保护顶点的位移。尾巴和翅膀还要从链根单独摆动。缺少控制或响应不合格的区域自动补链、重做局部权重并复测。保存后重新打开交付工程，再跑一次独立探针。验收报告记录各区初检、补骨名、根梢位移、串动和读回结果。未分类的显著身体后侧突出区、权重异常或复测失败会阻止放行。

复用旧版 Pi 整角绑定时，从所选来源另存通过检查的版本，再生成或复用该版本的动作。当前识别器用几何启发式定位区域；遇到卷曲、重叠、紧贴躯干或形似服装的附属件，结合装配四视图检查清单覆盖。验证新规则时同时保留原始漏绑、合并网格、单侧失效和补绑后再次运行的对照。

已确认裙装的前后层可能分属不同连通片。检查横跨两侧髋部的后摆是否延续裙面；后摆已有尾权重时退回服装分区重绑，再检查抬腿接触和裙长。

### 手持道具

手持件在静置姿态把实际握点对到持物侧掌心，再将整件刚性绑定到同侧腕骨。对独立的剑、魔杖，Pi 根据握柄候选端和掌心骨点初始化。带鞘或挂在腰背的装饰按实际安装位置处理。形状或左右手有歧义时，在道具对象设置局部坐标 `grip_local` 和持物侧 `grip_hand`（`Left` 或 `Right`）。回读静态工程检查掌心间隙和刚性权重，再在动作里量实际握点相对手掌的漂移。

## 按垂袖走向排骨

在左右袖片分别确认固定袖口、可弯曲区域与布尖。对于自由端向下的长袖，可以沿高度切取连续网格截面，用截交线的长度加权中心追踪片面走向，将关节放在中线转弯处。回卷或近水平的袖片应沿表面路径取截面。第一根骨继承同侧前臂并保留袖口支点。仅沿新链再分配原悬垂袖片的权重份额。对照正侧面轮廓并逐帧复核袖口固定点。

[fit_sleeve.py](scripts/fit_sleeve.py) 用于已有袖口接合和垂袖权重的静态工程；运行前核对脚本使用的对象名、骨名与取样范围。以 Blender 后台打开最新装配，传入 `-P fit_sleeve.py -- 新工程路径.blend`，同名 JSON 记录左右袖片的采样中线和实际骨位。

## 衣身、袖口和裙摆

复用已验收的 HumanArmature 身体与头部接合。以完整可见的身体测试衣物，静态工程和动作工程均移除身体遮罩。

### 贴身衣片必须随对应身体部位运动

1. 在静置网格上逐件登记贴身区、固定接缝和自由区，包括与裙摆合成一个对象的上衣、左右袖及分离的饰边。给每个贴身区指定同侧身体表面与预期驱动骨。胸腰对应躯干，上臂袖和前臂袖分别对应同侧上臂和前臂，肩缝与肘窝保留关节过渡。
2. 从本次验收的 body 在静置世界坐标中建立对应。在指定解剖区域内寻找身体三角面，按投影点的重心坐标插值三个顶点的骨骼权重并归一化。腋下、交叠处沿衣片连通性核对归属，防止袖片投到胸侧。回读各区顶点的有效变形权重、实际 Armature 目标和修改器开关，补齐漏绑顶点并修正绑错部位的顶点。
3. 自由裙摆、垂袖等使用局部动态或顶点缓存时，明确指定作用顶点组，确认贴身区的缓存影响为零。重开动作工程，先只启用身体蒙皮，再启用完整修改器栈，检查缓存有无盖掉原本正确的随动。局部接触修正放在蒙皮之后，限定到实际需要贴合的衣片。
4. 分别抬起单侧手臂并屈肘，检查肩缝、上臂袖、肘窝、前臂袖和袖口。其他贴身区用对应身体关节做同样的独立动作检查。在最终动作与子帧中跟踪同一批衣料点和静置时选定的身体三角面锚点，记录各区相对间距变化的 P95、最大值和最差时刻，结合静置间隙与身高判断。用同机位近景核对切向滑移、拉长和意外露肤。任一应绑区无响应、跟错骨、被缓存覆盖或仍有可见脱离，均退回该区修正，复测后才可放行。

### 衣身串入手臂权重的硬约束

- 给每件衣服在静置网格上标出独立衣身和裙片、左右袖片、允许混权的袖根接缝。用腋下截面和沿布面的连通关系确定边界，覆盖两侧衣身、独立饰边及同位置的 UV 分裂点。连袖、披肩等随臂结构按实际布片单列。分区保存到 case，并随拓扑变化重新识别。
- **限制写入范围。** 身体权重投影只在本区允许的身体三角面上找对应。补绑袖口、平滑权重时，只在同侧袖片和明确标记的接缝内传播；沿布面计算衰减，避免空间距离很近的侧裙被写入前臂权重。
- **逐点阻断。** 初绑后、每次袖口或权重修正后、重新打开交付工程后，对所有独立衣身和裙片调用 [check_panel_arm_weights.py](scripts/check_panel_arm_weights.py) 的 `check_panel_arm_weights(garment, panel_vertices)`。非标准骨架用 `arm_roots` 指定左右肩臂根骨。记录结果并要求每个分区的 `passed` 为真；缺少预期分区、顶点无效或任一点的肩臂骨链总权重超过数值容差，均停止放行。把误入的权重按同片有效邻点分回躯干或裙骨，保留真实袖片的随动。
- **动作与接触同时通过。** 关闭动作缓存并固定躯干、骨盆和衣物动态，分别单侧抬臂、屈肘。独立衣身的最大位移应在数值精度内，同侧袖片应有响应。恢复完整修改器栈，用同一动作、同一采样时刻及风险子帧，对比左右袖口与手臂、裙片与腿鞋的相交及袖口形变。权重或缓存作用区改变后重算受影响的接触；新增穿插、袖口拉伸或原有未解决的穿插均保留为失败。把权重检查和接触检查分别记录到 case。

- **播放时的衣身位移是独立放行条件。** 在静置网格上预先圈定应随躯干的贴身侧片、腋下衣身和固定接缝，覆盖左右及重合分裂点。将允许滑动的布片单独登记。固定区只留浮点回读容差；可滑动过渡区根据静置净空、接缝余量预先登记位移上限。每区记录顶点、依据、实测身体参考高度和归一化上限，禁止看过失败帧后扩大容差。
- 重开交付动作，在相同身体姿态下，按实际执行顺序依次求值已验收的基础蒙皮、各层二级变形或旧缓存、最终接触修正。基础参照须独立于受测缓存、修正形状键和动态骨。对同编号顶点的世界坐标调用 [check_panel_motion.py](scripts/check_panel_motion.py) 的 `check_panel_motion`，用完整三维位移捕获沿身体表面的滑动。同一批采样覆盖全动作整数帧和帧间，手臂接近、贴近及离开时加密；按区保存最差时刻、顶点、变形层和相对身高的偏移。同步回看最差姿态的腋下轮廓、袖根接缝和接触解除后的回位。
- 任一固定区或过渡区超限、出现可见拖拽，或分区、基准、帧间报告缺失，都阻止动作放行，即使串权重和穿模计数均为零。回到首个超限的层，移除旧缓存对贴身区的作用，限制接触修正到确有接触的自由布片并处理接缝过渡。重新烘焙后在同一批样本同时复查衣身位移、袖口形变、腿鞋接触和布长。

### 常见变形的定位与修正

- **腋下出现尖角**。固定出错帧与机位，依次查看静止网格、仅启用 Armature、叠加接触修改器后的轮廓。隔离转动单侧手臂，读取衣身侧片的骨骼权重。袖片与衣身在 A-pose 中可能贴得很近，可在腋缝下方取截面，按网格连通性识别两片袖和衣身，再沿布面向肩缝平滑过渡。只把衣身上误入的手臂权重还给脊柱和胸骨。用同一组侧片边对比姿态长度与静止长度。
- **袖口被扯大**。对需要保持开口形状的袖型，在静止袖口内侧取一圈横截线，保留每个交点所属网格边及插值比例。用这些相同的点逐帧测周长，并观察手从袖口露出的位置。让同侧前臂带动整圈袖口，把上臂到前臂的权重过渡留在肘部；独立的悬垂袖片沿自己的骨链摆动。检查 Shrinkwrap 和动作接触修正是否再次撑开袖口，让修正强度在接近袖口时渐退。
- **转身时裙摆抬起或长袍穿腿**。先隔离抬臂，区分裙身串权重与裙骨跟随骨盆旋转、抬腿引起的外翻。按裙片调整重力方向和跟随幅度。袖片单独检测身体，裙装按下节处理。

同一件衣服可能同时出现多种失真。固定问题帧、机位和受影响布片，从静止网格开始，依次启用骨骼蒙皮、贴合修改器和动作修正。先修最早出现异常的一层，再逐层恢复其余修改器，每次复测同一组边或同一圈截线。

把服装权重修正写回可复用的静态装配。动作复核使用相同机位、身体动作和帧号输出前后对照，并给出出错部位的局部指标。分别报告形状恢复情况和残余相交帧数；几何相交计数不能单独判断镜头中是否可见。

## 抬腿时袜筒凸出、侧裙变尖

- **先定位布面。** 在出错姿态用同一机位分别显示身体、鞋袜和衣装，找出构成突起的网格边。记录边两端的顶点索引、静止边长及骨骼权重。按上节的修改器顺序测同一条边的姿态长度，找出拉伸最早出现的位置。对很短的边同时记录长度增量和倍率，结合轮廓判断可见程度。
- **袜筒按整片归属分侧。** 贴近中线的袜口可能有顶点越过另一侧。先沿袜筒连通布面确认所属腿，再从同侧身体表面的三角面插值大腿、膝、踝和脚趾权重，并归一化。独立饰边按与袜筒的接合关系归侧。抬腿和交叉步时检查袜筒内侧相邻点是否被两条腿分别带走。
- **侧裙分别检查串权重和接触位移。** 隔离抬臂，检查尖角顶点及其邻点是否带有肘、腕或手指权重。把误入的影响按当地原有比例分回躯干和裙骨。恢复贴合与接触层后，若同一片边再次拉长，用静止边长约束摊开该片过于集中的位移，向邻边平滑渐退，再对实际接触的部位重算帧间修正。
- **形状和穿模分别验收。** 重新打开最终动作，在抬腿峰值、交叉步及相邻子帧对照同一条边的长度和同机位关键姿态轮廓。用相同布片重新检测裙装与下半身、裙装与鞋袜的相交；邻近袖片受影响时复查袖口周长和接缝。把问题边、修前修后测量、采样间隔和复核图留在 case 中。

## 分层裙甲的腰部凹陷与单侧顶起

- **腰下甲片出现凹口。** 沿凹口追踪同一条搭接边，在骨盆坐标中比较同一批顶点相对静置轮廓的径向内收量。若仅开蒙皮就出现折痕，检查相邻点的大腿、骨盆及裙根骨权重。对固定在腰带上的甲片，让搭接边获得连续的骨盆支撑，向侧片和自由下摆平滑过渡。重新启用贴合和旧动作补偿时，在已获得支撑的区域逐层复测，避免再次拉出凹口。
- **抬腿后单侧裙摆持续翘起。** 先将截图对到原动作和机位，标出画面中突起的甲片、布层及饰边。沿抬膝、落腿和收势连续查看膝前净空及各层下缘的高度。若直接压低裙片会露膝，用实际膝、靴轨迹限定需要让位的片区；硬甲保留搭接轮廓，软布与饰边保留接缝并随腿落下。换动作后从静态绑定重算这段支撑与回落。
- **复核外形。** 在相同姿态和尺度下并排看修前、修后，先复现反馈机位，再补角色正面，必要时看侧面。检查腰侧到膝前的轮廓是否连续、下摆能否自然回落，并按下节复测帧间接触。即使采样相交数为零，正面仍可暴露硬折角；将可见缺陷和当前保留版本记入 case，作为下次复核的起点。

## 默认裙骨与回正参数

按裙子语义识别自由裙片。绕腰布置 8 条纵向骨链，每链 3 节，共 24 根。根部支点随骨盆固定，下摆自由。沿同一周向方位由腰口向下取样，让骨段贴着静置裙面的整体外形，在主要转折处设关节。用正、背、左右视图确认骨链走向和裙面距离。

按整条静置链长与身体高度的比值调整回正速度。沿链累计各骨头到腰口的距离，根段取 0，末段取 1。长链回正较慢，同一条链由根到梢逐步减慢。默认回正频率限于 **1.78–3.64 Hz**，阻尼比由 **0.83 降到 0.65**，允许摆角由根至梢逐步放宽。项目的 [转身回放脚本](scripts/replay_turn.py) 会按此规则为 `Skirt.` 骨链重新烘焙弹簧响应，并将实际频率、阻尼比和摆角写入各骨骼的自定义属性。其他动作求解器沿用同一套静置参数。

默认物性用于初始化摆动。转身、交叉步、抬腿仍可能穿模；逐动作执行下文的裙片布长、裙面接触和帧间检查。发现相交时记录失败部位与时刻，检查局部修正后的边长及轮廓，保留完整身体。

### 缝合衣片与饰边的整体随动

- **先确认哪些部位缝在一起。** 在静置装配上沿实际接缝登记主布片、包边、刺绣或袖口滚边的对应关系。分离网格可用饰边顶点在同侧主布三角面上的重心坐标和静置偏移作锚点，沿接缝核对对应顺序。保留原有厚度、搭接量、开衩和自由端；材质颜色、对象名和空间近邻都不足以判定缝合关系。
- **让接缝两侧共享最终形变。** 主布完成蒙皮、二级运动和局部接触求解后，缝合区的饰边从对应主布面继承位移与朝向，保留原有截面。检查独立骨链或旧缓存有无再次移动同一批顶点。局部受压时，优先让接触到的衣片绕固定区转动、折叠，沿布面向邻片渐退；同时复测未接触侧的轮廓。
- **分别查接缝和布面。** 出现裂口或尖角时，对照静置网格和同机位动作近景。先量成对锚点间距相对静置的变化，再跟踪接缝两侧同一批非退化三角形的面积比、边长比及腰口或固定缝到自由边的材料路径。接缝仍贴合而布面接近塌成线或局部边异常拉长时，逐层回读蒙皮、动态和接触结果，修正最早造成失真的层。以静置设计为基准区分原有开口与动作中新增的裂缝。
- 在最终工程用同一批帧与风险子帧并列记录接缝漂移、布面失真、材料路径、衣物与相邻肢体或配件的相交，并回看最差时刻的完整轮廓。换动作时沿用静置锚点和测线，重新计算接触。个案的视觉验收与各项实测结果分别保存，跨角色复用判断方法，阈值按既有硬约束和本件衣物的静置结构取值。

## 裙片布长硬约束

带裙装的装配绑定必须同时通过纵向布长与接触复核。裙片可随抬腿弯折、绕膝滑动，也可在转身时滞后和回摆。骨链长度固定后，仍须在蒙皮和接触修正后的最终裙面上验收。

1. 在静置装配上按裙片布置从腰口或固定缝到自由下缘的材料测线。沿同一片布的连通网格边取点，覆盖前、后、左右、开衩两侧和参与接触的独立层。保存各测线的有序顶点索引及静置折线长度。接缝处只合并属于同一块布的重复点。
2. 在接触求解中同时约束裙面相邻顶点的静置边长和纵向测线的总长度。保持腰口及接缝连续，让抬膝的位移通过局部弯折和邻片滑移释放。每次施加碰撞位移后重新投影长度约束，再检测腿、鞋靴与受影响的相邻部件。
3. 重开最终工程，对整段动作和帧间样本，用原顶点索引在统一尺度下累加各段长度。按每条测线计算 `abs(动作布长 / 静置布长 - 1)`，取全部测线、全部样本的最大值。默认数值容差为 **0.0001%（相对误差 1e-6）**。任一测线超差、受检裙片穿腿或穿靴，或交付物缺少布长与接触记录，该动作均不得标记通过。换动作后重新求解、重新验收。
4. 同时记录局部边长倍率的 P99、最大值及对应布片和帧号，给出有代表性的抬腿、交叉步或急转关键姿态图。整条测线的伸缩可能相互抵消；即使测线通过，出现可见的膝前横向突出、尖角或局部拉长时，仍须回到对应裙片修正。测线索引、角色实测值和对照画面写入 case。

## 连衣裙的接触初始化与帧间复核

盲测从本次静态装配 mesh 和通用动作源开始，保留输入摘要及首次运行结果；旧角色的骨架、权重、布片分区和缓存不作为输入。先记录整件衣物与完整身体、鞋袜及相邻衣层的静置相交。依据静置几何和实际接缝登记裙面、内衬、饰边及材料测线，再核对绑定覆盖。直接按已有裙骨权重选测试面，会同时漏掉绑错的裙片。跨独立片的测线需有可复核的接缝对应；缺少对应时记作布长未验证。

出现可见露出时，固定帧和机位分别隐藏身体、鞋袜或内层，定位露出的对象。对同一组完整衣面与碰撞面依次测量身体动作加基础蒙皮、叠加裙骨动态、启用最终缓存三个阶段。分别记录腿和鞋的残余相交及布长。局部推离、平滑和长度投影后重新检测；达到迭代上限仍有残余时保留失败样本，回到最早出现问题的层。单次水平径向推离在高抬膝处可能把裙片推向靴面，需要结合局部接触方向与上下衣层复测。

交付前重开最终动作，由整段采样导出 CSV，列为 `frame,skirt-leg,skirt-footwear,min_length_ratio,max_length_ratio`；后四列依次为相交三角面对数和当时所有材料测线相对静置长度的最小、最大倍率。用 [check_skirt_samples.py](scripts/check_skirt_samples.py) 校验，传入 CSV 和 `--first`、`--last`、`--subdivisions`（每帧等分数）、`--paths`（实际有效测线数）。退出非零时阻止动作放行。数值通过后仍须复核各层覆盖、静置时允许的接合、可见轮廓和整衣穿插。二级骨探针的通过只用于确认该区域可动。

1. **确定碰撞面。** 在原动作上用变形后的完整裙装建基线，覆盖内外裙片、下摆和饰边，包括裙骨权重较低的区域。分别检测双腿及贴身裤口、两只靴子，记录相交的布片、碰撞对象和时刻。
2. **按裙型初始化。** 对腰部固定、下摆自由的裙装，先使用上节的裙骨默认物性，再从相近裙型的 case 读取候选接触参数。按角色尺度、静置间隙和裙片软硬调整碰撞余量、局部影响半径和回落阻尼。以腰部为支点，让受抬腿影响的裙片平滑抬起、随腿落下；局部仍相交时再沿接触面推开，让相邻内衬与饰边一起移动。以已验收的身体和靴子轨迹作为碰撞输入。
3. **按动作重算。** 更换动作或调整动作时序后，从静态绑定重新计算接触并烘焙。可复用裙片分区、支点和候选参数；旧动作的逐帧位移只随原动作保存。
4. **复核帧间穿模。** 重新打开烘焙工程，用比烘焙采样更密的时间步检查全段，覆盖相邻样本的中点。抬腿、交叉步和快速转身处发现穿插时，在实际出错的子帧修正，复测前后相邻区间及全段。发现轮廓突变时，从该处提取相邻子帧观察靴尖、裙层和饰边。按碰撞对象分别记录整数帧与含子帧的采样总数、相交时刻数及采样间隔。

### 在同一子帧检查穿模与布长

对拓扑和顶点顺序固定的网格，用 [rigging_review.py](scripts/rigging_review.py) 的 `CollisionRegion` 缓存各碰撞区的顶点索引及重编号三角面，保留原面序。每个子帧只推进一次场景，从同一依赖图读取各对象的最终世界坐标。用当时的位置重建各区碰撞树，供该子帧内的碰撞对共用。同时用 `SkirtLengths.measure` 检查同一裙面的材料测线及局部边长，并从相同坐标检查袖口和接缝。测线、焊缝对应和短边筛选沿用该角色的验收定义。网格拓扑或顶点顺序变化时重新建立映射。

改动检查器后，用同一动作和采样时刻逐项对照旧版的接触结果、每条材料测线及局部边长。分别记录复核耗时和包含分析、烘焙、渲染与关键帧目检的完整墙钟耗时。

## 用穿模复核反馈修正初始化

在 case 的运行目录记录碰撞双方、发生帧、静置间隙、身高归一化的穿入位置或修正位移，以及原参数、试过的参数、最终采用值和残余相交。下一例出现相近的衣型、护具或动作时，先调取这份记录作为候选初值。按新网格比例、硬度和关节活动范围换算，再用该角色的动作验证。记录中区分骨骼姿态修正、运动学碰撞间隙与实际使用的物理求解器参数。

- 交叉步穿靴时，同时测同侧腿、对侧腿和两只靴子。确认支撑脚和摆动脚，先根据靴筒高度估计膝踝容许弯曲量和摆动净空，平滑接入与退出交叉段，再求解靴内同侧腿的局部间隙。重新检查相邻裙片，避免把穿模转移到另一层。
- 交叉步的初值从已复核案例的 initialization.json 读取。先以父骨随动坐标测静置相对的有符号屈伸，按靴筒后缘与大腿的实际净空选膝屈上限，再校准踝背屈与侧倾。用按身高归一化的余量搜索摆动髋轨迹；大腿内侧残留先查骨盆权重与局部姿态修正。对裙片先绕腰部抬起，再用局部偏移处理余量。时间平滑后重新检测同帧，把会重新穿入的邻帧补偿减弱到可通过的程度。
- 硬护腕只有少数姿态在开口处相交时，先在腕骨局部坐标中搜索一段连续帧共用的最小刚性偏移，前后渐退。整圈形状、护板边长和接缝宽度参与复核。软布局部变形与硬壳刚性偏移分别保存初值。

## 完整计时与交付

在开始分析输入、选择起点或检查工程前记录起始时间。在查看最终动作、评估异常并保存结论和交付物后记录结束时间。以两者的墙钟时间差作为完整耗时。

- 注明起点是静态装配、单独部件还是已验收的绑定，以及本次实际复用的资产。已有静态装配的计时从读取该输入开始。
- 记录输入分析、身体拟合与检查、接头与部件绑定、动作烘焙和渲染、关键帧目检与指标分析、修正重试及最终结论的时间。脚本耗时作为明细；分析、排错、等待计算、读回工程和动作复核均计入总时长。
- 多角色并行时报告整批墙钟时间与各角色的执行区间。标明重叠阶段和共享分析，避免把并行时长相加或把共享时间平均分摊后当成实测值。对比不同顺序时统一输入起点、动作、复核项目与结束条件。
- 记录实际查看的动作与帧、残余问题，并交付可打开的静态工程、动作工程和预览。个案的计时明细和结论保存在对应运行目录。
